# dvr-media

Public hosting for DVR Design's social posts: the DVR Labs carousels and the promo films, which Buffer reads
from `raw.githubusercontent.com`. The daily DVR Labs routine (`labs/ROUTINE.md` §0 in the private site repo)
pushes each day's files here:

- `<date>/labs/` — the carousel: `00-cover.jpg`, then one slide per effect.
- `<date>/film/` — the posting copy of the promo film and its cover.

Only content that is being posted publicly lives here.
